1Decision tree

  • Asks "\(x_j \le s\) ?" again and again. Each answer cuts a region in two: rectangles.
  • Each cut makes the two sides as pure as possible (Gini \(= 1 - \sum_c p_c^2\), 0 when pure).
  • Few cuts: too simple (bias). Many cuts: learns the noise (variance).
The thread. Shallow trees are biased, deep trees are unstable. Boosting fixes the bias, bagging fixes the variance.

2Boosting: a team that learns from its mistakes

  • Weak learners (stumps, shallow trees) trained one after the other.
  • AdaBoost: after each learner, the misclassified points weigh more. The next learner focuses on them.
  • Prediction = weighted vote \(\operatorname{sign} \sum_t \alpha_t h_t(x)\). Accurate learner, larger \(\alpha_t\).
Purple: cuts of the newest learner. Point size ∝ weight it was trained with. Colour: vote of the team. Try "deep": the first tree is perfect on the training set, there is nothing left to correct.
  • Gradient boosting: a score \(F(x)\), probability \(p(x) = \sigma(F(x))\). Each new tree predicts what is still missing, the residuals \(r_i = y_i - p(x_i)\) (labels in \(\{0, 1\}\)). Add a fraction of it: \(F \leftarrow F + \eta\, h\).
  • \(r_i\) is minus the gradient of the cross-entropy in \(F\): each tree is a gradient descent step.
  • Learning rate \(\eta\): small = cautious steps. Too many trees or large \(\eta\): overfitting. Stop on validation data.
Colour: \(p(x)\) after \(T\) trees. Point size ∝ residual \(|r_i|\) that tree \(T\) was fitted to (large = still badly predicted). Purple: cuts of tree \(T\). Right: cross-entropy (log-loss) on training and test points.

3Bagging: a vote of independent experts

  • Bootstrap: redraw \(n\) points with replacement. Each sample gives a different deep tree.
  • Each tree overfits, but in different places. The vote cancels these accidental errors: less variance.
  • Random forest: each cut looks at a random subset of features. More diverse trees, better vote.
  • More trees never hurt: the error plateaus.
Noisier moons. Left: newest tree, fully grown, with its bootstrap sample (size ∝ copies, faded = not drawn). Right: vote of all trees, intensity = share of the votes. Below: one tree alone jumps around, the vote climbs and plateaus. "Same data": every tree is identical, the vote is one tree. The gain comes from diversity.
