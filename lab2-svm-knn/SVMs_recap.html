1Margin

$$h(x) = w^\top x + b, \qquad \hat y = \operatorname{sign} h(x), \qquad d(x) = \frac{|w^\top x + b|}{\|w\|}.$$
  • Scale invariance. \((\lambda w, \lambda b)\) defines the same hyperplane. Fix the scale: \(\min_i |w^\top x_i + b| = 1\).
  • Why \(2/\|w\|\). The closest points then satisfy \(w^\top x + b = \pm 1\), so \(d = 1/\|w\|\) on each side. Margin width \(= 2/\|w\|\).
Drag the two purple handles. The band is the widest empty band centred on your line.

2Hard margin

$$\max_{w,b} \frac{2}{\|w\|} \iff \min_{w,\,b}\ \tfrac12 \|w\|^2 \quad \text{s.t.} \quad y_i\,(w^\top x_i + b) \ge 1 \ \ \forall i.$$
  • Constraint: each point on its side, outside the band.
  • Convex quadratic: unique solution. Infeasible as soon as the classes overlap.

3Soft margin

$$\min_{w,\,b,\,\xi}\ \underbrace{\tfrac12 \|w\|^2}_{\text{wide margin}} + C \underbrace{\sum_i \xi_i}_{\text{violations}} \quad \text{s.t.} \quad y_i\,(w^\top x_i + b) \ge 1 - \xi_i,\ \ \xi_i \ge 0.$$
  • \(\xi_i\): depth of point \(i\) into the band. \(\xi_i = 0\) outside, \(0 < \xi_i < 1\) inside, \(\xi_i > 1\) misclassified.
  • \(C\): price of one unit of violation. Small \(C\): wide band, violations tolerated. Large \(C\): narrow band, few violations. \(C \to \infty\) forces \(\xi_i = 0\): hard margin (if separable).
  • Same shape as Ridge, penalty + loss, with \(C \approx 1/\lambda\).
Drag the points or add some, and move C. Red segments are the slacks \(\xi_i\) (divided by \(\|w\|\)).

4Dual and support vectors

Multipliers \(\alpha_i \ge 0\) for the margin constraints, \(\mu_i \ge 0\) for \(\xi_i \ge 0\):

$$L = \tfrac12\|w\|^2 + C\sum_i \xi_i - \sum_i \alpha_i\big(y_i(w^\top x_i + b) - 1 + \xi_i\big) - \sum_i \mu_i \xi_i .$$
StationarityResult
\(\partial_w L = 0\)\(w = \sum_i \alpha_i y_i x_i\)
\(\partial_b L = 0\)\(\sum_i \alpha_i y_i = 0\)
\(\partial_{\xi_i} L = 0\)\(\alpha_i = C - \mu_i \in [0, C]\)

Plugging \(w\) back into \(L\) gives the dual problem in \(\alpha\):

$$\max_{\alpha}\ \sum_i \alpha_i - \tfrac12 \sum_{i,j} \alpha_i \alpha_j\, y_i y_j\, \langle x_i, x_j\rangle \quad \text{s.t.} \quad 0 \le \alpha_i \le C,\ \ \sum_i \alpha_i y_i = 0.$$

Its solution \(\alpha\) gives the classifier:

$$h(x) = w^\top x + b = \sum_i \alpha_i y_i \langle x_i, x\rangle + b.$$
Support vectors = points with \(\alpha_i > 0\): on the edge or inside the band.
The data enter only through inner products \(\langle x_i, x_j\rangle\).

5Kernel trick

  • Lift. \(\varphi\) maps \(x\) to a feature space where the classes are linearly separable. Linear in \(\varphi(x)\) = non-linear in \(x\).
  • Trick. The dual only needs \(\langle \varphi(x_i), \varphi(x_j)\rangle\). Take \(K\) that computes it directly:
$$K(x, x') = \langle \varphi(x), \varphi(x')\rangle, \qquad h(x) = \sum_i \alpha_i\, y_i\, K(x_i, x) + b.$$
  • Example. \(K(x, x') = (1 + x^\top x')^p\): cost \(O(d)\) for any degree \(p\).
  • Valid kernel (Mercer): every Gram matrix \(K_{ij} = K(x_i, x_j)\) is symmetric positive semi-definite. Read \(K\) as a similarity.
\(\varphi(x) = (x_1, x_2, x_1^2 + x_2^2)\). A plane in \(\mathbb{R}^3\) is a circle in \(\mathbb{R}^2\). Find the height that separates the classes.
